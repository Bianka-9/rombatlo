# Rombatlo

Rombusz területének kiszámítására használható, annak átlóiból.
Felhaználónak meg kell adnia egy 'e' és egy 'f' értéket, amelyeknek legalább 1-nek kell lenniük. A gomb megnyomására megjelenik a számított érték.
